# STEP 1: INSTALL REQUIRED LIBRARIES
# Run this command in a separate Jupyter cell if required:
# !pip install qiskit qiskit-aer matplotlib

# STEP 2: IMPORT REQUIRED LIBRARIES

import matplotlib.pyplot as plt
from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator

# STEP 3: CREATE A 16-QUBIT QUANTUM CIRCUIT
# 16 qubits and 16 classical bits

n = 16

qc = QuantumCircuit(n, n)

# STEP 4: APPLY HADAMARD GATE TO ALL 16 QUBITS
# Hadamard gate creates an equal superposition of |0> and |1>

for i in range(n):
    qc.h(i)

# STEP 5: MEASURE ALL QUBITS
# Store the measurement results in classical bits

qc.measure(range(n), range(n))

# STEP 6: DISPLAY QUANTUM CIRCUIT

print("16-Qubit Quantum Circuit:")
print(qc.draw(output='text'))

# STEP 7: SIMULATE THE QUANTUM CIRCUIT

simulator = AerSimulator()

compiled_circuit = transpile(qc, simulator)

job = simulator.run(compiled_circuit, shots=1)

result = job.result()

# STEP 8: GET RANDOM NUMBER

counts = result.get_counts()

binary_number = list(counts.keys())[0]

# Remove spaces if present
binary_number = binary_number.replace(" ", "")

# Ensure exactly 16 bits
binary_number = binary_number.zfill(16)

# STEP 9: DISPLAY OUTPUT

decimal_number = int(binary_number, 2)

print("\n========== QUANTUM RANDOM NUMBER GENERATOR ==========")

print("Number of Qubits:", n)

print("Random 16-bit Binary Number:", binary_number)

print("Random Decimal Number:", decimal_number)

print("=====================================================")

# STEP 10: DISPLAY RANDOM BITS

bits = [int(bit) for bit in binary_number]

plt.figure(figsize=(12, 3))

plt.bar(range(1, 17), bits)

plt.xlabel("Qubit Number")
plt.ylabel("Measured Bit")
plt.title("16-Qubit Quantum Random Number Generator")

plt.xticks(range(1, 17))
plt.yticks([0, 1])

plt.grid(axis='y')

plt.show()

### A. QUANTUM COMPUTING FUNDAMENTALS

**Q1. What is Quantum Computing?**

Quantum Computing is a type of computing that uses principles of quantum mechanics to perform computations using quantum bits called qubits.

**Q2. What is a qubit?**

A qubit is the basic unit of quantum information. Unlike a classical bit, which can be either 0 or 1, a qubit can exist in a superposition of both states.

**Q3. What is the difference between a classical bit and a qubit?**

- Classical bit stores either 0 or 1.
- Qubit can exist in a superposition of 0 and 1.
- Classical computers use classical logic gates.
- Quantum computers use quantum gates.

**Q4. What are the possible states of a qubit?**

The two computational basis states are:

- |0⟩ – Zero state.
- |1⟩ – One state.

A general qubit state is:

|ψ⟩ = α|0⟩ + β|1⟩

**Q5. What is superposition?**

Superposition is a quantum property in which a qubit can exist in a combination of multiple possible states until it is measured.

**Q6. What is quantum measurement?**

Quantum measurement is the process of observing a qubit, which produces a classical result, either 0 or 1 in the computational basis.

**Q7. What is quantum entanglement?**

Quantum entanglement is a phenomenon in which two or more qubits become correlated such that their states cannot be described independently.

**Q8. What is a quantum gate?**

A quantum gate is an operation that changes the state of one or more qubits.

Examples:
1. Hadamard gate
2. Pauli-X gate
3. Pauli-Y gate
4. Pauli-Z gate
5. CNOT gate
