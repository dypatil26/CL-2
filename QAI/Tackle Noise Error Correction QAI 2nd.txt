# STEP 1: IMPORT REQUIRED LIBRARIES

from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram
import matplotlib.pyplot as plt


# STEP 2: CREATE QUANTUM CIRCUIT

# 3 data qubits
# 2 ancilla qubits for error detection
# 2 classical bits for syndrome
# 1 classical bit for final measurement

qc = QuantumCircuit(5, 3)

# STEP 3: INITIALIZE QUANTUM STATE

# Prepare logical state |1>

qc.x(0)


# STEP 4: ENCODE THE QUANTUM INFORMATION

# Encode |1> as |111>

qc.cx(0, 1)
qc.cx(0, 2)

qc.barrier()


# STEP 5: INTRODUCE BIT-FLIP NOISE

# Simulate bit-flip error on qubit 1

qc.x(1)

qc.barrier()


# STEP 6: ERROR DETECTION

# First parity check between q0 and q1

qc.cx(0, 3)
qc.cx(1, 3)

# Second parity check between q1 and q2

qc.cx(1, 4)
qc.cx(2, 4)

qc.barrier()


# STEP 7: MEASURE ERROR SYNDROME

# Classical bit 1 stores first parity
# Classical bit 2 stores second parity

qc.measure(3, 1)
qc.measure(4, 2)


# STEP 8: CORRECT THE DETECTED ERROR

# Syndrome 01: Error on qubit 2
with qc.if_test((qc.clbits[2], 1)):
    with qc.if_test((qc.clbits[1], 0)):
        qc.x(2)

# Syndrome 11: Error on qubit 1
with qc.if_test((qc.clbits[1], 1)):
    with qc.if_test((qc.clbits[2], 1)):
        qc.x(1)

# Syndrome 10: Error on qubit 0
with qc.if_test((qc.clbits[1], 1)):
    with qc.if_test((qc.clbits[2], 0)):
        qc.x(0)

qc.barrier()


# STEP 9: DECODE QUANTUM INFORMATION

qc.cx(0, 1)
qc.cx(0, 2)

qc.barrier()


# STEP 10: MEASURE FINAL LOGICAL QUBIT

qc.measure(0, 0)


# STEP 11: DISPLAY QUANTUM CIRCUIT

print("\nQUANTUM ERROR CORRECTION CIRCUIT\n")

print(qc.draw(output='text'))


# STEP 12: SIMULATE THE CIRCUIT

simulator = AerSimulator()

compiled_circuit = transpile(qc, simulator)

job = simulator.run(
    compiled_circuit,
    shots=1024
)

result = job.result()

counts = result.get_counts()


# STEP 13: DISPLAY RESULTS

print("\n========== ERROR CORRECTION RESULTS ==========")

print("Measurement Counts:", counts)

total = sum(counts.values())

correct = 0

for state, count in counts.items():

    # Classical bit 0 is the final logical measurement
    logical_bit = state.replace(" ", "")[-1]

    if logical_bit == '1':
        correct += count

print("Total Measurements:", total)

print("Corrected Logical 1:", correct)

print("Corrected Logical 0:", total - correct)

if correct == total:
    print("SUCCESS: Error corrected successfully!")
else:
    print("Error correction was not successful.")


# STEP 14: DISPLAY HISTOGRAM

plot_histogram(counts)

plt.title("Quantum Error Correction Results")

plt.show()

print("\nExperiment Completed Successfully!")

### A. BASIC QUANTUM ERROR CORRECTION CONCEPTS

**Q1. What is quantum error correction?**

Quantum Error Correction (QEC) is a technique used to detect and correct errors occurring in quantum information due to noise and environmental disturbances.

**Q2. Why is quantum error correction required?**

Quantum systems are highly sensitive to environmental disturbances. Noise can change qubit states and cause computational errors. Error correction helps protect quantum information.

**Q3. What is quantum noise?**

Quantum noise refers to unwanted disturbances that affect the state of a qubit during quantum computation.

**Q4. What are the common types of quantum errors?**

The three common types are:

1. Bit-flip error.
2. Phase-flip error.
3. Bit-phase-flip error.

**Q5. What is a bit-flip error?**

A bit-flip error changes the state of a qubit from 0 to 1 or from 1 to 0.

Example:

| Original | After Error |
|---|---|
| |0⟩ | |1⟩ |
| |1⟩ | |0⟩ |

**Q6. What is a phase-flip error?**

A phase-flip error changes the phase of a quantum state without changing its computational basis value.

For example:

|+⟩ = (|0⟩ + |1⟩)/√2

becomes

|−⟩ = (|0⟩ − |1⟩)/√2.

**Q7. What is the 3-qubit bit-flip code?**

It is a quantum error correction technique that uses three physical qubits to encode one logical qubit.

Logical encoding:

|0⟩ → |000⟩

|1⟩ → |111⟩

It can detect and correct a single bit-flip error.

**Q8. What is a logical qubit?**

A logical qubit is quantum information encoded across multiple physical qubits to protect it against errors.

### B. QUANTUM CIRCUIT AND GATES

**Q9. How many qubits are used in your practical?**

We use five qubits:

- Three data qubits.
- Two ancilla qubits for error detection.

We also use three classical bits for storing the measurement results.

**Q10. What is an ancilla qubit?**

An ancilla qubit is an additional qubit used for operations such as error detection, measurement and computation without directly measuring the encoded data qubits.

**Q11. What is the purpose of the X gate?**

The Pauli-X gate flips the state of a qubit.

|0⟩ becomes |1⟩.

|1⟩ becomes |0⟩.

**Q12. What is the purpose of the CNOT gate?**

CNOT stands for Controlled-NOT gate.

It flips the target qubit if the control qubit is in state 1.

**Q13. How do you encode logical state |1⟩ in your practical?**

First, we apply the X gate to qubit 0 to prepare |1⟩.

Then we apply CNOT gates to copy the computational-basis value into qubits 1 and 2.

The encoded state becomes:

|1⟩ → |111⟩.

**Q14. Why do we use barrier() in the quantum circuit?**

A barrier is used to separate different stages of a quantum circuit and prevent certain compiler optimizations from moving operations across that boundary.

**Q15. What is the purpose of qc.if_test() in your code?**

It performs conditional quantum operations based on previously measured classical bits.

In our practical, it applies an X gate to the qubit identified by the error syndrome.

### C. ERROR DETECTION AND CORRECTION

**Q16. What is an error syndrome?**

An error syndrome is a set of measurement results that identifies whether an error has occurred and helps determine its location.

**Q17. What is a parity check?**

A parity check determines whether two bits are equal or different.

- Same values: Even parity, result 0.
- Different values: Odd parity, result 1.

**Q18. Why do we use two ancilla qubits?**

We use two ancilla qubits to perform two parity checks on the three data qubits.

These checks help identify which data qubit has experienced a bit-flip error.

**Q19. Explain the two parity checks in your practical.**

First parity check:

CNOT(q0, q3) and CNOT(q1, q3).

It checks the parity between q0 and q1.

Second parity check:

CNOT(q1, q4) and CNOT(q2, q4).

It checks the parity between q1 and q2.

**Q20. What are the possible error syndromes in your practical?**

The syndrome values are:

| Syndrome (classical bits 1, 2) | Error location |
|---|---|
| 00 | No error |
| 10 | Qubit 0 |
| 11 | Qubit 1 |
| 01 | Qubit 2 |

**Q21. How does the circuit correct an error?**

After measuring the syndrome, the circuit identifies the erroneous qubit and applies an X gate to that qubit to reverse the bit-flip error.

**Q22. Why do we not directly measure the three data qubits during error detection?**

Directly measuring data qubits can disturb or collapse the encoded quantum state. Instead, ancilla qubits are used to measure parity information.

**Q23. What is decoding in quantum error correction?**

Decoding is the process of converting encoded quantum information back into its original logical representation.

In our practical, CNOT gates are applied to decode the three-qubit encoded state.

PRACTICAL 2: TACKLE NOISE WITH ERROR CORRECTION USING QISKIT

1. AIM

To implement a quantum error correction technique using Qiskit to detect and correct bit-flip errors in a quantum circuit using a three-qubit repetition code.

2. DESCRIPTION

Quantum computers are sensitive to noise and errors. A bit-flip error changes the quantum state from |0> to |1> or from |1> to |0>.

Quantum Error Correction (QEC) is a technique used to detect and correct errors without directly disturbing the encoded quantum information.

In this experiment, we use a three-qubit repetition code.

The logical state |1> is encoded into three qubits as |111>.

A bit-flip error is intentionally introduced on qubit 1. Two ancilla qubits are used to perform parity checks and detect the error.

Based on the measured error syndrome, the circuit identifies the affected qubit and applies an X gate to correct the error.

Finally, the quantum information is decoded and measured to verify whether the original logical state has been recovered.

3. LIBRARIES USED

1. Qiskit: Used to create and manipulate quantum circuits.
2. Qiskit Aer: Used to simulate the quantum circuit.
3. Matplotlib: Used to display the measurement histogram.
4. Qiskit Visualization: Used to visualize measurement results.

4. IMPORTANT QUANTUM GATES

1. X Gate:
   Performs a bit flip. It changes |0> to |1> and |1> to |0>.

2. CNOT Gate:
   Flips the target qubit when the control qubit is |1>.

3. Measurement:
   Converts the quantum state into a classical result.

4. Barrier:
   Separates different stages of the quantum circuit for better visualization.

5. ERROR SYNDROME

An error syndrome is a set of measurement results used to identify which qubit has an error.

Syndrome       Error Location
00             No error
01             Error on qubit 2
11             Error on qubit 1
10             Error on qubit 0

6. CODE EXPLANATION (STEP-BY-STEP)

STEP 1: IMPORT REQUIRED LIBRARIES

from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram
import matplotlib.pyplot as plt

Explanation:

- QuantumCircuit is used to create a quantum circuit.
- transpile converts the circuit into instructions suitable for the simulator.
- AerSimulator simulates the quantum circuit.
- plot_histogram displays the measurement results.
- matplotlib.pyplot is used to display the histogram.

STEP 2: CREATE QUANTUM CIRCUIT

qc = QuantumCircuit(5, 3)

Explanation:

We create a quantum circuit containing:

- 3 data qubits: Store the encoded quantum information.
- 2 ancilla qubits: Used for error detection.
- 3 classical bits: Store two syndrome measurements and one final measurement.

Total quantum bits = 5
Total classical bits = 3

STEP 3: INITIALIZE QUANTUM STATE

qc.x(0)

Explanation:

The X gate is applied to qubit 0.

Initially, the qubit is in state |0>. Applying the X gate changes it to |1>.

Therefore, the initial quantum state becomes |1>.

STEP 4: ENCODE THE QUANTUM INFORMATION

qc.cx(0, 1)
qc.cx(0, 2)

Explanation:

We encode the logical state |1> into three data qubits.

- The first CNOT copies the computational-basis value of qubit 0 to qubit 1.
- The second CNOT copies the computational-basis value of qubit 0 to qubit 2.

The encoded state becomes:

|1> -> |111>

Now, all three data qubits contain the encoded logical information.

STEP 5: INTRODUCE BIT-FLIP NOISE

qc.x(1)

Explanation:

We intentionally introduce a bit-flip error on qubit 1 using the X gate.

The encoded state changes from:

|111> -> |101>

This simulates a bit-flip error in the quantum system.

STEP 6: ERROR DETECTION

qc.cx(0, 3)
qc.cx(1, 3)

qc.cx(1, 4)
qc.cx(2, 4)

Explanation:

We use two ancilla qubits to perform parity checks.

First parity check:
- Qubit 0 and qubit 1 are connected to ancilla qubit 3.
- The result identifies whether qubits 0 and 1 have different values.

Second parity check:
- Qubit 1 and qubit 2 are connected to ancilla qubit 4.
- The result identifies whether qubits 1 and 2 have different values.

These parity checks help identify the location of the bit-flip error.

STEP 7: MEASURE ERROR SYNDROME

qc.measure(3, 1)
qc.measure(4, 2)

Explanation:

The two ancilla qubits are measured.

- The first parity result is stored in classical bit 1.
- The second parity result is stored in classical bit 2.

The two measurement results form the error syndrome.

For the introduced error on qubit 1, the syndrome is 11.

STEP 8: CORRECT THE DETECTED ERROR

with qc.if_test((qc.clbits[2], 1)):
    with qc.if_test((qc.clbits[1], 0)):
        qc.x(2)

with qc.if_test((qc.clbits[1], 1)):
    with qc.if_test((qc.clbits[2], 1)):
        qc.x(1)

with qc.if_test((qc.clbits[1], 1)):
    with qc.if_test((qc.clbits[2], 0)):
        qc.x(0)

Explanation:

The circuit checks the measured syndrome and applies an X gate to the affected qubit.

- Syndrome 01: Applies X gate to qubit 2.
- Syndrome 11: Applies X gate to qubit 1.
- Syndrome 10: Applies X gate to qubit 0.
- Syndrome 00: No correction is required.

Since we introduced an error on qubit 1, the syndrome is 11.

Therefore, an X gate is applied to qubit 1, restoring the original encoded state:

|101> -> |111>

STEP 9: DECODE QUANTUM INFORMATION

qc.cx(0, 1)
qc.cx(0, 2)

Explanation:

After correcting the error, we decode the quantum information.

Two CNOT gates are applied to remove the repetition encoding.

The encoded state |111> becomes:

|111> -> |100>

Now, qubit 0 contains the original logical information, while qubits 1 and 2 return to |0>.

STEP 10: MEASURE FINAL LOGICAL QUBIT

qc.measure(0, 0)

Explanation:

The first data qubit is measured and its result is stored in classical bit 0.

Since the original logical state was |1>, the expected final measurement is 1.

STEP 11: DISPLAY QUANTUM CIRCUIT

print(qc.draw(output='text'))

Explanation:

This statement displays the complete quantum circuit in text format.

It shows the initialization, encoding, noise introduction, error detection, correction, decoding, and measurement operations.

STEP 12: SIMULATE THE CIRCUIT

simulator = AerSimulator()

compiled_circuit = transpile(qc, simulator)

job = simulator.run(
    compiled_circuit,
    shots=1024
)

result = job.result()

counts = result.get_counts()

Explanation:

- AerSimulator() creates a quantum circuit simulator.
- transpile() converts the circuit into simulator-compatible instructions.
- shots=1024 executes the circuit 1024 times.
- job.result() collects the simulation results.
- get_counts() returns the number of occurrences of each measurement outcome.

STEP 13: DISPLAY RESULTS

print("Measurement Counts:", counts)

total = sum(counts.values())

correct = 0

for state, count in counts.items():

    logical_bit = state.replace(" ", "")[-1]

    if logical_bit == '1':
        correct += count

print("Total Measurements:", total)
print("Corrected Logical 1:", correct)
print("Corrected Logical 0:", total - correct)

Explanation:

- Measurement counts display the frequency of each output.
- total stores the total number of measurements.
- correct counts how many times the final logical bit is 1.
- The last bit after removing spaces represents classical bit 0, which stores the final logical measurement.
- The program checks whether all measurements successfully recovered the logical value 1.

If all 1024 measurements produce logical bit 1, the program displays the success message.

STEP 14: DISPLAY HISTOGRAM

plot_histogram(counts)

plt.title("Quantum Error Correction Results")

plt.show()

Explanation:

- plot_histogram() displays the measurement counts graphically.
- plt.title() sets the histogram title.
- plt.show() displays the graph.

The histogram helps us visualize the final measurement results.
