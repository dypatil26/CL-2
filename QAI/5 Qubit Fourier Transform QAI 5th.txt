!pip install -q qiskit

# STEP 2: IMPORT REQUIRED LIBRARIES

from qiskit import QuantumCircuit
import math

# STEP 3: DEFINE NUMBER OF QUBITS

n = 5

# STEP 4: CREATE 5-QUBIT QUANTUM CIRCUIT

qc = QuantumCircuit(n)

# STEP 5: IMPLEMENT QUANTUM FOURIER TRANSFORM

for j in range(n):

    # Apply Hadamard gate
    qc.h(j)

    # Apply controlled phase gates
    for k in range(j + 1, n):

        angle = 2 * math.pi / (2 ** (k - j + 1))

        qc.cp(angle, k, j)

# STEP 6: APPLY SWAP GATES
# Reverse the order of qubits

for i in range(n // 2):

    qc.swap(i, n - i - 1)

# STEP 7: DISPLAY QUANTUM CIRCUIT

print("\n========== 5-QUBIT QUANTUM FOURIER TRANSFORM ==========\n")

print(qc.draw(output='text', fold=-1))

print("\n=======================================================")

# STEP 8: DISPLAY CIRCUIT INFORMATION

print("\nNumber of Qubits:", n)

print("Hadamard Gates:", n)

print("Controlled Phase Gates:", n * (n - 1) // 2)

print("SWAP Gates:", n // 2)

print("Total Gates:", qc.size())

print("\nQFT circuit implemented successfully!")

PRACTICAL 5: IMPLEMENTING A 5-QUBIT QUANTUM FOURIER TRANSFORM (QFT)

1. AIM

To implement a 5-qubit Quantum Fourier Transform (QFT) circuit using Python and Qiskit.

2. DESCRIPTION

Quantum Fourier Transform (QFT) is a quantum algorithm that transforms a quantum state from the computational basis into the Fourier basis.

It is the quantum version of the Discrete Fourier Transform (DFT).

QFT is used in various quantum algorithms, such as Shor's factoring algorithm and quantum phase estimation.

In this experiment:
- A quantum circuit containing five qubits is created.
- Hadamard gates are applied to the qubits.
- Controlled phase gates are used to introduce phase rotations.
- SWAP gates reverse the order of the qubits.
- Finally, the complete QFT circuit is displayed.

3. LIBRARIES USED

1. Qiskit: Used to create and manipulate quantum circuits.
2. Math: Used to calculate phase rotation angles.

4. IMPORTANT QUANTUM GATES

1. Hadamard Gate (H):
   Creates superposition by transforming the computational basis states.

2. Controlled Phase Gate (CP):
   Applies a phase rotation to the target qubit depending on the state of the control qubit.

3. SWAP Gate:
   Exchanges the states of two qubits.

for j in range(n):

Explanation:

3. The inner loop applies controlled phase gates between the current qubit and the remaining qubits.
4. The phase angle is calculated using:

   angle = 2π / 2^(k-j+1)

5. The controlled phase gate applies the calculated phase rotation.

The Hadamard gates create superposition, while the controlled phase gates introduce phase relationships between qubits.

Together, these operations implement the QFT transformation.

Explanation:

- QFT circuit operations produce the output qubits in reversed order.
- SWAP gates are used to reverse the qubit order.
- The loop exchanges the first qubit with the last qubit and the second qubit with the fourth qubit.
- The middle qubit remains unchanged.

For five qubits, the SWAP operations are:

SWAP(0, 4)
SWAP(1, 3)
