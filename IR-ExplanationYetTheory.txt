PART 1 — FUNDAMENTALS OF INFORMATION RETRIEVAL
Before studying individual practicals, you must understand what Information Retrieval actually means.
1. What is Information Retrieval?
Information Retrieval (IR) is the process of searching, finding and retrieving relevant information from a large collection of documents based on a user's query.

In simple language:

Suppose you search on Google:
Best machine learning courses


Google searches through a huge collection of webpages and returns the pages that are relevant to your query.

This entire process is an example of Information Retrieval.

Other examples:
- Searching emails in Gmail.
- Searching documents on Google.
- Searching books in a digital library.
- Searching research papers.
- Searching products on Amazon.
- Searching files on your computer.
Definition to tell the external:

"Information Retrieval is the process of finding relevant documents or information from a large collection of data based on a user's search query."
2. What is a Document?
A document is a unit of information that contains some text or content.

In Information Retrieval, a document can be:
- A PDF file.
- A webpage.
- An email.
- A research paper.
- A Word document.
- A news article.
For example:
Document 1:
Machine Learning is a branch of Artificial Intelligence.

Document 2:
Deep Learning uses neural networks.

Document 3:
Information Retrieval helps users find relevant documents.


Here, we have three documents.
3. What is a Corpus?
A corpus is a collection of documents used for text processing, searching or analysis.

For example:

Suppose we have 1,000 research papers related to Artificial Intelligence.

All 1,000 papers together form a corpus.

Difference:
- Document = One individual text file or information unit.
- Corpus = Collection of documents.
4. What is a Query?
A query is the search term or question entered by the user to retrieve relevant information.

Example:
Query: Artificial Intelligence


The retrieval system searches the document collection and returns documents containing relevant information.
5. What is a Search Engine?
A search engine is a software system that searches a collection of information and retrieves relevant results based on a user's query.

Examples:
- Google
- Bing
- DuckDuckGo
A search engine generally performs:
1. Document collection.
2. Text preprocessing.
3. Index creation.
4. Query processing.
5. Document matching.
6. Ranking.
7. Displaying search results.

6. What is the difference between Information Retrieval and Database Retrieval?
Information Retrieval	Database Retrieval
Finds relevant documents	Finds exact structured records
Usually works with unstructured or semi-structured data	Usually works with structured data
Results may be ranked by relevance	Results usually satisfy specified conditions
Uses text processing and indexing	Uses SQL and database queries
Example: Google search	Example: SQL SELECT query

Example:

Information Retrieval:
Find documents about Machine Learning.


Database Retrieval:
SELECT * FROM students WHERE marks > 80;


7. What is Text Processing?
Text processing means applying different operations to raw text to make it suitable for searching and analysis.

For example:

Original text:
The Students are studying Machine Learning!


After preprocessing:
student study machine learning


We remove unnecessary words, convert words into a consistent format and prepare the text for further processing.

This is important because computers cannot directly understand raw human language in the same way humans do.
8. What is NLP?
NLP stands for Natural Language Processing.

It is a field of Artificial Intelligence that enables computers to process, understand and work with human languages.

Examples:
- Chatbots.
- Language translation.
- Sentiment analysis.
- Spam detection.
- Text summarization.
- Voice assistants.
Difference between IR and NLP:
- NLP focuses on processing and understanding human language.
- IR focuses on finding relevant information from document collections.
NLP techniques are often used inside an Information Retrieval system.
9. What is Indexing?
Indexing is the process of organizing information so that documents can be searched quickly.

Suppose we have:
D1: Machine Learning is interesting.
D2: Deep Learning is powerful.
D3: Machine Learning uses data.


An index stores information about which documents contain which words.

For example:
Word	Documents
Machine	D1, D3
Learning	D1, D2, D3
Deep	D2
Data	D3

This helps us find documents without checking every document from beginning to end.
10. What is Document Ranking?
Document ranking means arranging retrieved documents according to their relevance to the user's query.

For example:

Query:
Machine Learning


Results:
1. Document about Machine Learning.
2. Document about Deep Learning.
3. Document about Computer Networks.
The most relevant document should generally appear first.
11. What is Relevance?
Relevance means how closely a document matches the information requested by the user.

For example:

Query:
Python programming


A document explaining Python programming is highly relevant.

A document about cooking is not relevant.
12. What are Precision and Recall?
These are two important evaluation measures in Information Retrieval.








revisiondojo.com


A. Precision
Precision tells us how many retrieved documents are actually relevant.
\[
Precision=\frac{Relevant\ Retrieved}{Total\ Retrieved}
\]

Example:

A system retrieves 10 documents.

Out of these, 8 are relevant.
\[
Precision=\frac{8}{10}=0.8
\]

Therefore:
\[
Precision=80\%
\]

B. Recall
Recall tells us how many of all relevant documents were successfully retrieved.
\[
Recall=\frac{Relevant\ Retrieved}{Total\ Relevant}
\]

Example:

There are 20 relevant documents in the complete collection.

The system retrieves 8 of them.
\[
Recall=\frac{8}{20}=0.4
\]

Therefore:
\[
Recall=40\%
\]

Difference
Precision	Recall
Measures correctness of retrieved results	Measures completeness of retrieved results
Focuses on relevant results among retrieved documents	Focuses on relevant results found from all relevant documents
High precision means fewer irrelevant results	High recall means fewer relevant documents are missed

13. What is F1-Score?
F1-score combines precision and recall into one measure.
\[
F1=2\times\frac{Precision\times Recall}{Precision+Recall}
\]

It is the harmonic mean of precision and recall.

It is useful when we want to balance both measures.
14. What is a Retrieval Model?
A retrieval model is a mathematical or computational method used to determine how documents match a query.

Important models include:
1. Boolean Retrieval Model.
2. Vector Space Model.
3. Probabilistic Retrieval Model.
4. Language Model for Information Retrieval.
A. Boolean Retrieval Model
This model uses Boolean operators:
- AND
- OR
- NOT
Example:
Machine AND Learning


Returns documents containing both words.
Machine OR Learning


Returns documents containing either word or both.
Machine NOT Learning


Excludes documents containing Learning.
B. Vector Space Model
In this model, documents and queries are represented as numerical vectors.

We calculate similarity between vectors to find relevant documents.

TF-IDF and cosine similarity are commonly used with this model.
C. Probabilistic Retrieval Model
This model estimates the probability that a document is relevant to a user's query.

It ranks documents based on estimated relevance.

1. What is Text Preprocessing?
Text preprocessing is the process of cleaning and transforming raw text into a structured format that can be used by computers for further analysis.

In simple language:

Suppose we have this sentence:
The Students are Studying Information Retrieval!


It contains:
- Capital letters.
- Common words.
- Different word forms.
- Punctuation.
We process this text to make it easier to search and analyze.

Why is this useful?

Because different forms of the same word may have similar meanings.

For example:
Study
Studies
Studying
Studied


We may want to treat these as related words during retrieval.
2. Why is Text Preprocessing Required?
Text preprocessing is required because raw text contains unnecessary and inconsistent information.

It helps us:
1. Remove unnecessary words.
2. Reduce word variations.
3. Improve search efficiency.
4. Reduce vocabulary size.
5. Prepare text for machine learning.
6. Improve the consistency of document representation.

The common preprocessing pipeline is:

4. What is Lowercasing?
Lowercasing means converting all uppercase letters into lowercase letters.

Example:

Original:
MACHINE Learning


After lowercasing:
machine learning


Why do we use it?

Because computers may treat uppercase and lowercase words as different strings.

For example:
Machine
machine
MACHINE


Lowercasing helps treat them consistently.
5. What is Tokenization?








sendbird.com


Tokenization is the process of breaking a large piece of text into smaller units called tokens.

A token can be:
- A word.
- A sentence.
- A punctuation mark.
- Another text unit, depending on the tokenizer.
There are two common types.
A. Sentence Tokenization
It divides a paragraph into individual sentences.

Example:
Python is easy. AI is interesting.


Output:
Sentence 1: Python is easy.
Sentence 2: AI is interesting.


B. Word Tokenization
It divides a sentence into individual words.

Example:
Information Retrieval is useful.


Output:
["Information", "Retrieval", "is", "useful"]


Important term: Token

A token is an individual unit produced during tokenization.

Why is tokenization important?

Because most text-processing operations work on individual tokens rather than complete paragraphs.
6. What is Stop Word Removal?








medium.com


Stop words are common words that often carry relatively little information for a particular retrieval task.

Examples:
is, am, are, the, a, an, in, on, of, and


Stop word removal means removing such words from the tokenized text.

Example:

Original:
The student is studying in the college.


After stop word removal:
student studying college


Why do we remove stop words?
1. They occur frequently.
2. They may contribute little to a particular search task.
3. Removing them can reduce the size of the index.
4. It can reduce unnecessary processing.
Important point
Not every common word should always be removed.

For example:
To be or not to be


Removing all stop words would destroy the meaning of this sentence.

Similarly, words such as "not" are important in sentiment analysis.

So, stop word removal depends on the application.
7. What is Stemming?








larevueia.fr


Stemming is the process of reducing different forms of a word to a common stem by removing prefixes or suffixes using linguistic rules.

Example:
Original word	Possible stem
Playing	Play
Played	Play
Plays	Play
Connected	Connect
Connecting	Connect

Stemming reduces different word forms to a common representation.
What is a Stemmer?
A stemmer is an algorithm or tool that performs stemming.
What is Porter Stemmer?
Porter Stemmer is a popular stemming algorithm used in Natural Language Processing.

It removes common suffixes using a series of rules.

For example, it can reduce:
playing
played
plays


to:
play


However, a stem does not always have to be a valid dictionary word.

For example, Porter Stemmer can reduce variations of "argue" to "argu".

This is an important characteristic of stemming.
8. What is Lemmatization?
Lemmatization is the process of converting a word into its meaningful dictionary base form, called a lemma.

Examples:
Original word	Lemma
Studies	Study
Better	Good (with appropriate context/POS)
Running	Run
Children	Child
Was	Be

Lemmatization uses vocabulary and morphological information to find the correct base form.
Difference between Stemming and Lemmatization
Very important viva question
Stemming	Lemmatization
Removes word endings using rules	Finds the dictionary base form
Usually faster	Usually more computationally intensive
May produce invalid words	Produces meaningful dictionary words
Does not generally require context	Can use context and part of speech
Example: arguing → argu	Example: studies → study

External explanation:

"Stemming removes prefixes or suffixes to produce a common stem, whereas lemmatization converts a word into its meaningful dictionary form."
9. What is POS Tagging?
POS stands for Part of Speech.

POS Tagging is the process of assigning grammatical categories to words in a sentence.

Common parts of speech include:
Part of Speech	Meaning	Example
Noun	Name of person, place or thing	Student
Verb	Action	Study
Adjective	Describes a noun	Intelligent
Adverb	Describes an action or adjective	Quickly
Pronoun	Replaces a noun	He

Example:

Possible tags:

It is useful in:

1. What is Document Retrieval?
Document Retrieval is the process of finding documents from a collection based on a user's search query.

Example:

Suppose we have three documents:
D1: Python is a programming language.

D2: Machine Learning uses Python.

D3: Information Retrieval searches documents.


User enters:
Python


The retrieval system should return:
D1
D2


Because both documents contain the word Python.

This is document retrieval.
2. What is an Inverted File?
An Inverted File is a data structure used in Information Retrieval to store a mapping between words and the documents in which those words occur.

It is also commonly called an Inverted Index.

In simple language:

Instead of storing each document with its list of words, we store each word with the list of documents containing that word.

This makes searching faster.
Understand the difference
Normal document representation:
Document	Words
D1	Python, programming, language
D2	Machine, learning, Python
D3	Information, retrieval, documents

Inverted file representation:
Word	Document IDs
Python	D1, D2
Programming	D1
Language	D1
Machine	D2
Learning	D2
Information	D3
Retrieval	D3
Documents	D3

Notice the difference.

In the normal representation, we store words under documents.

In the inverted representation, we store documents under words.

That is why it is called an inverted index.
3. Why is it called an Inverted Index?
Because the original relationship is:
Document → Words


But we reverse this relationship:
Word → Documents


This reversed mapping makes it easier to find documents containing a particular word.
4. What are the main components of an Inverted Index?
There are two important components.
A. Dictionary / Vocabulary
The dictionary contains all unique words found in the document collection.

Example:
Python
Machine
Learning
Information
Retrieval
Programming


Each unique word is stored only once in the vocabulary.
B. Posting List
A posting list contains the document IDs in which a particular word occurs.

Example:
Python → D1, D2

Learning → D2

Retrieval → D3


Here:
- Python is the term.
- D1 and D2 are the postings.
- The complete list is called the posting list.








slideshare.net


5. What is a Term?
A term is a word or token used for indexing and retrieval.

For example:
Machine Learning is useful.


Possible terms:
- Machine
- Learning
- Useful
Terms are generally generated after preprocessing.
6. What is Document ID?
A Document ID is a unique identifier assigned to each document.

For example:
D1 = First document
D2 = Second document
D3 = Third document


These IDs are used in the inverted index to identify where a term appears.
7. What is Document Frequency?
Document Frequency (DF) tells us how many documents contain a particular term.

Formula:
\[
DF(t)=\text{Number of documents containing term }t
\]

Example:
Python → D1, D2, D4


Therefore:
\[
DF(Python)=3
\]

Remember: Document frequency counts documents, not total word occurrences.
8. What is Term Frequency?
Term Frequency (TF) tells us how many times a particular term occurs in a document.

Example:
D1:
Python is useful.
Python is easy.
Python is popular.


Python appears three times.

Therefore:
\[
TF(Python,D1)=3
\]

Difference between TF and DF
TF	DF
Counts occurrences of a word inside a document	Counts documents containing the word
Can be calculated separately for each document	Calculated across the document collection
Example: Python occurs 3 times in D1	Python occurs in 4 documents

9. What is a Positional Index?
A positional index is an extension of an inverted index.

It stores not only the document IDs but also the positions where a term occurs in each document.

Example:
D1: Python is easy and Python is popular.


Positional index:
Python → D1: [1, 5]
Easy   → D1: [3]
Popular → D1: [7]


Why is this useful?

It supports phrase queries.

For example:
"Python is easy"


The system can check whether the words occur next to one another in the correct order.
10. What is Boolean Retrieval?
Boolean Retrieval uses logical operators to search documents.

There are three major operators.
A. AND
AND returns documents containing both search terms.

Example:
Python AND Machine


If:
Python → D1, D2, D3
Machine → D2, D3, D4


Then:
Result → D2, D3


B. OR
OR returns documents containing either search term or both.
Python OR Machine


Result:
D1, D2, D3, D4


C. NOT
NOT excludes documents containing a particular term.
Python NOT Machine


Result:
D1

11. What is Query Processing?
Query Processing is the process of understanding and preparing a user's search query before retrieving documents.

Suppose the user searches:
Python Programming


The system may:
1. Convert the query into lowercase.
2. Tokenize it.
3. Remove selected stop words.
4. Apply stemming if configured.
5. Search the inverted index.

Query matching means comparing the search terms with the terms stored in the inverted index.

For example:

The system looks up:

Then retrieves documents D1 and D2.
13. What is Ranking in Document Retrieval?
A basic inverted index can retrieve matching documents, but it does not automatically provide a relevance ranking.

For ranking, we can use methods such as:
- Term Frequency.
- TF-IDF.
- Cosine similarity.
- BM25.
The purpose is to display the most relevant documents first.
14. What is TF-IDF?
Very important viva topic
TF-IDF stands for:

Term Frequency–Inverse Document Frequency.

It is a numerical technique used to measure the importance of a word in a document relative to a collection of documents.

It combines two measurements.
A. Term Frequency
It measures how frequently a term appears in a particular document.

A common formula is:
\[
TF(t,d)=\frac{f_{t,d}}{\text{Total terms in }d}
\]

Where:

- \(f_{t,d}\) = Number of occurrences of term \(t\) in document \(d\).
B. Inverse Document Frequency
IDF measures how rare or informative a term is across the document collection.

A common formula is:
\[
IDF(t)=\log\left(\frac{N}{DF(t)}\right)
\]

Where:
- \(N\) = Total number of documents.
- \(DF(t)\) = Number of documents containing term \(t\).
C. TF-IDF
\[
TFIDF(t,d)=TF(t,d)\times IDF(t)
\]

Example:

Suppose there are 10 documents.

The word Python occurs in 2 documents.
\[
IDF(Python)=\log(10/2)
\]

A word that appears in many documents generally has a lower IDF, while a rarer word generally has a higher IDF.

This helps give greater importance to distinctive words.

Your available text-analysis reference also explains TF-IDF as the product of term frequency and inverse document frequency. 
Data_Science_LabManual.pdf

15. What is Cosine Similarity?
Cosine Similarity measures the similarity between two vectors based on the angle between them.

It is used to compare a query vector with document vectors.

Formula:
\[
Cosine(A,B)=
\frac{A\cdot B}{\|A\|\|B\|}
\]

Where:
- \(A\) = Query vector.
- \(B\) = Document vector.
- \(A\cdot B\) = Dot product.
- \(\|A\|\) and \(\|B\|\) = Vector magnitudes.
A value closer to 1 indicates greater similarity in the usual nonnegative TF-IDF setting.

Example:

Query:
Machine Learning


Document A:
Machine Learning is useful.


Document B:
Cooking is interesting.


Document A should have a higher cosine similarity.

2. Efficient query processing.

1. What is Probability?
Probability is the mathematical measure of how likely an event is to occur.

Its value ranges between 0 and 1.
\[
0\leq P(A)\leq1
\]

Where:
- 0 means the event is impossible.
- 1 means the event is certain.
Example:

Suppose we have a fair coin.

Probability of heads:
\[
P(H)=\frac12=0.5
\]

Probability of tails:
\[
P(T)=\frac12=0.5

2. What is Conditional Probability?
Conditional Probability means the probability of an event occurring when another event is already known to have occurred.

It is represented as:
\[
P(A|B)
\]

Read it as:

"Probability of A given B."

Formula:
\[
P(A|B)=\frac{P(A\cap B)}{P(B)}
\]

Example:

Suppose we want to calculate the probability that a patient has heart disease given that the patient has high cholesterol.

We write:
\[
P(HeartDisease|HighCholesterol)
\]

This is a conditional probability.

It does not mean that high cholesterol proves heart disease. It means we are estimating the probability of disease under that observed condition.
3. What is Bayes' Theorem?
Extremely important viva topic
Bayes' Theorem is a mathematical formula used to calculate the probability of an event based on previously known information.

Formula:
\[
P(A|B)=\frac{P(B|A)P(A)}{P(B)}
\]

Where:
- \(P(A|B)\) = Posterior probability.
- \(P(B|A)\) = Likelihood.
- \(P(A)\) = Prior probability.
- \(P(B)\) = Evidence.
Let's understand each term.
A. Prior Probability
Prior probability is the initial probability of an event before considering new evidence.

Example:

The probability of heart disease in a population before examining a particular patient's test results.
B. Likelihood
Likelihood measures how probable the observed evidence is under a particular hypothesis.

Example:

The probability of observing high cholesterol among patients who have heart disease.
C. Evidence
Evidence is the overall probability of the observed information.
D. Posterior Probability
Posterior probability is the updated probability after considering the available evidence.

Example:

The probability of heart disease after considering a patient's age, cholesterol and other medical observations.

External explanation:

"Bayes' Theorem updates the probability of an event when new evidence becomes available. It combines prior probability and likelihood to calculate posterior probability."
4. What is a Bayesian Network?
Most important practical concept
A Bayesian Network is a probabilistic graphical model that represents relationships and dependencies between different variables using a directed acyclic graph.

In simple language:

It is a graphical model that shows how different factors are probabilistically related.

For heart disease diagnosis, we can consider:
- Age.
- Blood pressure.
- Cholesterol.
- Chest pain.
- Blood sugar.
- Heart disease.
A Bayesian network represents these variables and their probabilistic relationships.

B. Directed Edges
Directed edges represent probabilistic dependencies between variables.

Example:

This represents a modeled dependency between age and heart disease.

Important: A directed edge does not automatically prove direct causation. It represents a conditional dependency in the chosen probabilistic model.

A DAG is a graph with:
- Directed edges.
- No directed cycles.

This is a directed acyclic structure.

Because it contains a cycle.

Why is DAG important?

Because a Bayesian Network uses a DAG to represent probabilistic dependencies without circular directed relationships.

9. What is Joint Probability?
Joint probability means the probability that multiple events occur together.

It is represented as:
\[
P(A,B)
\]

For a Bayesian Network, the joint probability distribution can be factorized using the graph structure.

For variables \(X_1,X_2,\ldots,X_n\):
\[
P(X_1,\ldots,X_n)
=
\prod_{i=1}^{n}
P(X_i|Parents(X_i))
\]

This is a fundamental Bayesian Network formula.

7. What is Hierarchical Clustering?
Very important viva topic

8. What is Agglomerative Hierarchical Clustering?








utsavdesai26.medium.com


Agglomerative Hierarchical Clustering is a bottom-up clustering algorithm.

It starts by treating every data point as a separate cluster.

Then it repeatedly:
1. Calculates distances between clusters.
2. Identifies the closest clusters.
3. Merges them.
4. Updates the cluster distances.
5. Repeats the process.
The process continues until the desired number of clusters is obtained.
9. How does Agglomerative Clustering work?
Suppose we have five data points:
A, B, C, D, E


Initially, each point is a separate cluster:
{A} {B} {C} {D} {E}


Suppose A and B are closest.

We merge them:
{A,B} {C} {D} {E}


Now suppose D and E are closest.

We merge them:
{A,B} {C} {D,E}


Now suppose C is closest to the cluster .

We merge:
{A,B,C} {D,E}


Finally, both clusters can be merged.
{A,B,C,D,E}


This is the complete bottom-up process.

	A	B	C

Interpretation:
- Distance between A and B = 2.

11. What is Euclidean Distance?
Important viva topic
Euclidean Distance is the straight-line distance between two points in a multidimensional space.

For two points:
\[
A=(x_1,y_1)
\]

\[
B=(x_2,y_2)
\]

Formula:
\[
d(A,B)=
\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}
\]

Example:

Suppose:
\[
A=(2,3)
\]

\[
B=(5,7)
\]

Then:
\[
d(A,B)=
\sqrt{(5-2)^2+(7-3)^2}
\]

\[
=\sqrt{9+16}
\]

\[
=\sqrt{25}=5
\]

Therefore, the Euclidean distance is 5.

It is commonly used in clustering.
12. What are Linkage Methods?
Very important viva topic
Linkage methods determine how the distance between two clusters is calculated.

There are four important linkage methods.
A. Single Linkage
Single Linkage calculates the minimum distance between any two points belonging to different clusters.

Formula:
\[
D(A,B)=
\min_{a\in A,b\in B}d(a,b)
\]

In simple language:

It considers the two closest points from the two clusters.
B. Complete Linkage
Complete Linkage calculates the maximum distance between any two points belonging to different clusters.

Formula:
\[
D(A,B)=
\max_{a\in A,b\in B}d(a,b)
\]

In simple language:

It considers the two farthest points from the two clusters.
C. Average Linkage
Average Linkage calculates the average distance between all pairs of points from two clusters.

Formula:
\[
D(A,B)=
\frac{1}{|A||B|}
\sum_{a\in A}\sum_{b\in B}d(a,b)
\]

It considers the average distance between the clusters.
D. Ward Linkage
Ward Linkage merges clusters that result in the smallest increase in within-cluster variance.

In simple language:

It tries to combine clusters in a way that keeps the groups compact.








perfecxion.ai


Difference between linkage methods
Method	How distance is calculated
Single	Minimum distance
Complete	Maximum distance
Average	Average distance
Ward	Minimum increase in within-cluster variance

Remember this for viva:
- Single = Minimum.
- Complete = Maximum.
- Average = Mean.
- Ward = Minimum increase in variance.
13. What is a Dendrogram?








ned.ipac.caltech.edu


A Dendrogram is a tree-like diagram that represents the hierarchy of clusters.

It shows:
- Which data points are merged.
- The order of merging.
- The distance at which clusters are merged.
- The hierarchy of clusters.
How to read a Dendrogram?
The horizontal axis generally represents the data points.

The vertical axis represents the distance or linkage value at which clusters merge.

A lower merge indicates more similar clusters under the chosen distance and linkage method.

A higher merge indicates that more distant clusters are being combined.
14. What is a Dendrogram Cut?
A Dendrogram Cut means drawing a horizontal line across the dendrogram to decide how many clusters should be formed.

For example:

If we cut the dendrogram at a suitable height, it may produce three clusters.

If we cut it at another height, it may produce two clusters.

Therefore, the cut height determines the number of clusters.

16. What is Feature Scaling?
Feature Scaling is the process of bringing numerical features to comparable scales.

Example:

Suppose a dataset has:
Age: 20 to 80

Salary: 10,000 to 1,00,000


Salary has a much larger numerical range.

If we use Euclidean distance directly, salary may dominate the distance calculation.

Feature scaling helps prevent this problem.

Common techniques:
A. Standardization
It transforms data using the mean and standard deviation.
\[
z=\frac{x-\mu}{\sigma}
\]

Where:
- \(x\) = Original value.
- \(\mu\) = Mean.
- \(\sigma\) = Standard deviation.
B. Min-Max Normalization
It scales data into a specified range, commonly 0 to 1.
\[
x'=\frac{x-x_{min}}{x_{max}-x_{min}}
\]

Feature scaling is important in distance-based clustering.
17. What is the Number of Clusters?
The number of clusters is the number of groups we want the data to be divided into.

In Agglomerative Clustering, we can specify the desired number of clusters.

For example:

This means we want the algorithm to produce three clusters.

Alternatively, we can examine the dendrogram and choose an appropriate cut height.

A cluster label is an identifier assigned to each data point to indicate which cluster it belongs to.

Example:

B → Cluster 0

D → Cluster 2


The numerical labels are identifiers, not rankings.

Cluster 0 is not necessarily better than Cluster 1.
19. What is Silhouette Score?
Silhouette Score is a measure used to evaluate the quality of clustering.

It measures how well a data point fits into its own cluster compared with neighbouring clusters.

Formula:
\[
S=\frac{b-a}{\max(a,b)}
\]

Where:
- \(a\) = Average distance to points in the same cluster.
- \(b\) = Lowest average distance to points in another cluster.
Interpretation:
Score	Meaning
Close to +1	Good clustering
Around 0	Overlapping clusters
Negative	Possible incorrect assignment

The score generally ranges from -1 to +1.
20. What is Intra-Cluster Distance?
Intra-cluster distance measures how far points are from other points within the same cluster.

A smaller intra-cluster distance generally indicates a more compact cluster.
21. What is Inter-Cluster Distance?
Inter-cluster distance measures the separation between different clusters.

A larger inter-cluster distance generally indicates better separation.
22. Complete Working of Agglomerative Hierarchical Clustering
Input Dataset

Numerical data points

Preprocessing and Scaling

Calculate Distance Matrix

Select Closest Clusters

Merge Clusters

Repeat Until Desired Number of Clusters

Final Clusters and Dendrogram

Step-by-step explanation
Step 1: Load the dataset.

We take a dataset containing numerical observations.

Step 2: Preprocess the dataset.

We handle missing values and select suitable numerical features.

Step 3: Apply feature scaling.

We scale the features so that large numerical ranges do not dominate distance calculations.

Step 4: Calculate distances.

We calculate distances between data points using a distance measure such as Euclidean distance.

Step 5: Initialize individual clusters.

Every data point starts as a separate cluster.

For example:
{A} {B} {C} {D} {E}


Step 6: Find the closest clusters.

We identify the two clusters with the smallest linkage distance.

Step 7: Merge the clusters.

We combine the closest clusters into a single cluster.

Step 8: Repeat the process.

We recalculate cluster distances and continue merging.

Step 9: Stop.

We stop when the desired number of clusters is reached.

Step 10: Visualize the result.

We can use a dendrogram to visualize the hierarchy.

Five definitions you should never forget:
1. Information Retrieval: Finding relevant information from a collection of documents.
2. Inverted Index: A data structure that maps words to the documents containing them.
3. Bayesian Network: A probabilistic graphical model representing dependencies using a DAG.
4. Naive Bayes: A probabilistic classification algorithm based on Bayes' Theorem and conditional independence assumptions.
5. Agglomerative Clustering: A bottom-up clustering algorithm that repeatedly merges the closest clusters.
