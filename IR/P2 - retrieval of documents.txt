import re
import pandas as pd
from collections import defaultdict

# Document Collection
documents = {
    1: "Machine learning is a branch of artificial intelligence",
    2: "Artificial intelligence is transforming healthcare",
    3: "Information retrieval helps users search documents",
    4: "Machine learning and data mining are important",
    5: "Deep learning is a subset of machine learning",
    6: "Search engines use information retrieval techniques",
    7: "Data science uses machine learning algorithms",
    8: "Artificial intelligence uses deep learning"
}

print("DOCUMENT COLLECTION:\n")

for doc_id, text in documents.items():
    print("Document", doc_id, ":", text)

# Preprocessing Function
def preprocess(text):
    text = text.lower()
    words = re.findall(r'\b[a-z]+\b', text)
    return words

# Construct Inverted Index
inverted_index = defaultdict(set)

for doc_id, text in documents.items():
    words = preprocess(text)

    for word in words:
        inverted_index[word].add(doc_id)

print("\nINVERTED INDEX:\n")

for word in sorted(inverted_index):
    print(word, ":", sorted(inverted_index[word]))

# Display Index Table
index_table = []

for word, doc_ids in sorted(inverted_index.items()):
    index_table.append({
        'Term': word,
        'Document Frequency': len(doc_ids),
        'Posting List': sorted(doc_ids)
    })

index_df = pd.DataFrame(index_table)

print("\nINVERTED INDEX TABLE:")
print(index_df.to_string(index=False))

# Boolean AND Search
def search_and(query):
    terms = preprocess(query)

    if not terms:
        return set()

    result = inverted_index.get(terms[0], set()).copy()

    for term in terms[1:]:
        result = result.intersection(inverted_index.get(term, set()))

    return result

# Boolean OR Search
def search_or(query):
    terms = preprocess(query)
    result = set()

    for term in terms:
        result = result.union(inverted_index.get(term, set()))

    return result

# Interactive Search
print("\nDOCUMENT RETRIEVAL SYSTEM")

query = input("Enter search query: ")
operation = input("Enter operation (AND/OR): ").upper()

if operation == "AND":
    result = search_and(query)
elif operation == "OR":
    result = search_or(query)
else:
    result = set()
    print("Invalid operation!")

print("\nSEARCH RESULTS:")

if result:
    for doc_id in sorted(result):
        print("\nDocument ID:", doc_id)
        print("Content:", documents[doc_id])
else:
    print("No matching documents found.")

## Top 30 Viva Questions and Answers

### A. Basic Information Retrieval Concepts

**Q1. What is Information Retrieval (IR)?**

Information Retrieval is the process of finding relevant information or documents from a large collection based on a user's search query.

Example: Searching for information on Google.

**Q2. What is a document retrieval system?**

A document retrieval system is a system that searches a collection of documents and retrieves documents that match the user's query.

**Q3. What is an inverted index?**

An inverted index is a data structure that maps each term or word to the list of documents in which that word appears.

Example:

machine → [1, 4, 5, 7]

It means the word machine appears in documents 1, 4, 5 and 7.

**Q4. Why do we use an inverted index?**

We use an inverted index to make document searching faster and more efficient instead of scanning every document for every query.

**Q5. What is the difference between a normal index and an inverted index?**

- Normal index: Maps documents to the terms present in them.
- Inverted index: Maps terms to the documents containing them.

**Q6. What is a term in Information Retrieval?**

A term is an individual word extracted from a document after preprocessing.

Example: "Machine learning is useful"

Terms: Machine, learning, is, useful.

**Q7. What is a posting list?**

A posting list is the list of document IDs in which a particular term appears.

Example:

learning → [1, 4, 5, 7]

**Q8. What is document frequency?**

Document Frequency (DF) is the number of documents in which a particular term appears.

Example:

If the word "machine" occurs in documents 1, 4, 5 and 7, its document frequency is 4.

**Q9. What is a search query?**

A search query is a word or combination of words entered by a user to retrieve relevant documents.

Example: "machine learning".

**Q10. What are Boolean retrieval models?**

Boolean retrieval models retrieve documents using logical operators such as AND, OR and NOT.

### B. Preprocessing Concepts

**Q11. What is text preprocessing?**

Text preprocessing is the process of cleaning and preparing raw text before indexing or searching.

Common steps include:
- Lowercasing
- Tokenization
- Removing special characters
- Stopword removal
- Stemming
- Lemmatization

**Q12. Why do we convert text into lowercase?**

Example: "Machine" and "machine" are treated as the same term.

**Q13. What is tokenization?**

Tokenization is the process of splitting text into smaller units called tokens, usually words.

Example:

"Machine learning is useful"

Output: ['machine', 'learning', 'is', 'useful']

**Q14. What is the purpose of regular expressions in your code?**

Regular expressions are used to identify patterns in text.

In our code:

It extracts sequences of lowercase English letters as words.

**Q15. What is the difference between stemming and lemmatization?**

- Stemming removes word endings to obtain a word stem, which may not be a valid dictionary word.
- Lemmatization converts a word into its meaningful dictionary base form.

Example:
- Stemming: studies → studi
- Lemmatization: studies → study

AND search retrieves only those documents that contain all the terms present in the query.
